# 숫자별 카드 장면 설계 v2

사용자 요구: 생성 전에 카드별 상황·배경·자세·시점·소품을 확정한다. 생성 후 기존 카드 및 같은 종류 전체와 비교하고, 소품만 바뀐 유사 구도는 재생성한다.

## 고정 요소와 변화 요소

- 고정: 승인된 캐릭터의 외형·배색·우주복, 종류별 테두리·문양·이름표 위치. 초록 이름은 코모도.
- 변화: 몸 전체 실루엣, 얼굴 방향, 화면 속 위치와 크기, 카메라 높이·각도, 작업 행동, 배경 공간과 조명.
- 같은 종류에서 작업·자세·시점이 겹치면 생성 전에 수정한다. 기존 시안은 외형과 틀만 참조하고 중앙 그림의 자세는 복사하지 않는다.
- 1번 승인 시안은 기준 카드로 유지한다. 검수에서 통과한 기존 그림은 유지하고, 아래 변경 대상만 새로 생성한다.
- 숫자 좌상단 정방향·우하단 180도 회전, 6·9 밑줄, 1024×1536, 가독성 확인.

## 검수 기록 원칙

공통 뒷면: 40장 모두 같은 파일 사용. 짙은 남색 우주·은색 이중 테두리·중앙 궤도 문장. 위아래 반대 방향의 흰 로켓 2개와 물방울(파랑)·잎(초록)·태양(노랑)·초승달(검정 바탕 아이보리) 문양을 각각 180도 대칭 쌍으로 배치한다. 숫자·캐릭터·글자 없음. 어떤 종류인지 뒷면에서 구분되지 않도록 모두 동일. 세로 2:3. 비대칭 상하 표시·앞면 이름·개별 색 테두리 금지.

1. 생성 전 이 표와 프롬프트를 대조한다. 요청한 상황·자세·시점이 모두 문장으로 들어가야 한다.
2. 생성 후 기존 버전과 비교한다. 같은 종류 카드 전체에서도 얼굴 위치·몸 실루엣·시선·배경 구조를 비교한다.
3. 작업과 배경이 달라도 같은 중앙 자세면 불합격. 숫자·이름 오류도 불합격.
4. 재생성본 역시 자동 채택하지 않는다. 통과한 카드만 최종 manifest에 연결한다.
5. 원본 v1은 보존하고 수정 후보는 v2로 저장한다. 결과와 제외 이유를 REVIEW.ko.md에 남긴다.
