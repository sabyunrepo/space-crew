# 카드 시안 제작

상태: 사용자 시안 승인 완료. 숫자별 장면을 사전 설계하고 유사 구도19장을 교체했다. 현재 스폰지밥7번까지 앞면40/40장과 공통 뒷면1장 완료. [검수 기록](REVIEW.ko.md) 참고.

시안 파일: [v1 폴더](../../assets/cards/previews/v1/). 생성 방식은 내장 image_gen이며 전체 프롬프트는 [PROMPTS.md](./PROMPTS.md)에 보관했다. 종류별 테두리 세부 형태와 숫자 서체는 시안 간 소폭 차이가 있어 컨펌 후 공통 틀을 확정한다.

| 종류 | 캐릭터/피사체 | 장면 |
| --- | --- | --- |
| 파랑 | 한교동 — 사용자 표기 ‘한교통’을 한교동으로 해석 | 우주복을 입고 서비스 패널 정비 |
| 초록 | 코모도 — 귀여운 오리지널 도마뱀 | 우주복을 입고 산소 순환 장치 수리 |
| 노랑 | 스폰지밥 | 우주복을 입고 제어 콘솔 수리 |
| 검정 | 케로로의 타마마 | 우주복을 입고 전력 배터리 교체 |
| 흰색 | 흰색 로켓 | 격납고 정비 장면 |

공통: 세로 2:3, 둥근 모서리, 선명한 2D 카툰, 종류별 테두리, 양끝 숫자·문양, 한국어 이름표. 모바일에서 캐릭터와 숫자가 읽히는 구도를 우선한다.

원작 분홍색 카드를 검정색으로 표시하는 시각적 변경이며 카드 수·서열은 유지한다. 추후 미션 46 등의 ‘분홍’ 참조는 내부 suit ID와 분리하여 한국어 UI에서 ‘검정’으로 일관되게 표시해야 한다. 로켓은 흰색이지만 일반 색상 카드와 구분되는 으뜸패다.

현재 채택본과 이전 버전을 함께 보관한다. 목표 카드36개는 대응하는 플레이 카드 일러스트를 재사용하도록 manifest에 연결했다.

사용자 수정: 초록 캐릭터의 표시 이름은 **코모도**. 이미지는 유지하고 이름표만 변경한다.

사용자 확정: 모든 플레이 카드의 숫자마다 작업·포즈·도구·배경이 다른 독립 일러스트를 사용한다. 숫자만 바꾼 복제 카드는 만들지 않는다.
