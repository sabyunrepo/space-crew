# 50개 미션 구현·검증 결과

적용일: 2026-09-14 · 현재 규칙 버전: `crew-p9-50-3` · 3/4/5인 기본형

## 적용 범위

미션 **1~50**을 공유 규칙 엔진, 로컬 데모, Node 실시간 서버에 적용했다. 직접 시작 번호와 랜덤 50개 추첨, 실패 시 동일 미션 재도전, 성공 시 다음 미션, 마지막 미션 캠페인 종료를 지원한다. 구버전 1~4 저장 상태의 누락 필드는 복원 시 보완한다.

- 절대 순번, 상대 순서, Ω와 마지막 실제 트릭을 각각 판정한다. 동시 획득 목표는 집합으로 검사한다.
- 대원 지정, 지휘관 결정·목표 분배, 토큰 교환·이동, 5인 목표 양도, 구조 신호를 재접속 가능한 준비 단계로 구현했다.
- 지연 교신·정보 축소 D·지정자 교신 금지, 12번 첫 트릭 카드 이동, 0목표 특수 승리 조건과 구간별 트릭 담당을 서버에서 판정한다.
- 응답·담당자·진행량을 상시 표시한다. 플레이어별 캐릭터·신호 카드/토큰·낸 카드·목표 배치는 유지한다. 준비 중 비공개 목표와 다른 대원의 교환 카드 선택은 개인 snapshot에 노출하지 않는다.
- 데모 대원도 본인에게 공개된 snapshot만으로 준비와 플레이를 진행한다. 데모는 최적 전략으로 성공을 보장하는 AI가 아니다.
- 원격 Supabase의 `CrewRepository`는 미구현 상태다. Edge 계약·OpenAPI를 갱신했으나 셀프호스팅 DB/Edge와 Vercel에 배포하지 않았다. 실제 네트워크 검증 대상은 Node REST/WebSocket 서버다.

## 규칙 근거와 채택 정책

[미션 조건](./MISSIONS.ko.md), [판정 기록](./MISSION-RULINGS.ko.md)을 따른다. 지휘관 결정/분배는 공식 Thames & Kosmos 영문판으로 통일했다. 독일어 2019 판본의 절차 차이는 별도로 기록했다. 12번은 저자 답변의 중계에 근거한다. v3에서 5·33번의 지휘관 제외와 17번의 일반 9 전부 소진 조건을 정정했다. 직접 확인한 사본과 공식 공통 규칙을 적용한 근거 및 판본 차이는 [원작 재대조](./ORIGINAL-MISSION-AUDIT.ko.md)를 따른다.

## 검증 구분

- `source_reviewed`: 50개 목표 수·토큰·특수 조건을 기준 문서와 대조했다.
- `rulings_resolved`: 구현에 필요한 판정을 정했다. `정책` 표시는 C/I 해석을 채택한 항목이며 공식 확정과 다르다.
- `engine_tested`: 각 미션 × 3/4/5인 성공 종결 fixture, 위반 fixture, 실제 합법 명령 진행 및 매 준비 단계 JSON 복원을 검사했다. 성공 fixture는 이전 조건을 충족한 종결 상태를 구성하므로 전 미션을 무작위 배분부터 성공까지 풀었다는 뜻은 아니다.
- `multiplayer_tested`: 각 미션 × 3/4/5인을 실제 RoomStore에서 서로 다른 인증 토큰으로 진행하고, 디스크 재시작·개인 snapshot·중복 명령·동일 결과·실패 후 재도전을 검사했다. 이것은 프로세스 내 저장소 통합 검사다.
- `브라우저`: 표시된 미션만 서로 독립된 PC/모바일 브라우저 컨텍스트에서 실제 HTTP/WebSocket과 준비·카드 제출 UI로 결과까지 진행했다. 모든 50개 × 모든 인원의 브라우저 전수 검증은 아니다.

## 실행 결과

- 최초 v2 검증의 `npm test`: 12개 파일, 739개 테스트 통과. 엔진 50개 × 인원 3종 × 검증 3종에 개별 경계 검사를 더하고, RoomStore 150건 및 기존 계약·인증·SQL 테스트를 포함한다.
- `npm run typecheck`: 통과.
- `npm run contracts`: 파생 Edge 계약·미션 목록 및 OpenAPI 갱신.
- `npm run test:e2e`: PC·모바일 50개 시나리오 통과. 초기 실행 48개 통과 후, 구버전 랜덤 1~4 안내를 기대하던 2개를 1~50으로 수정해 두 환경 모두 재검증했다.
- 4번 성공 후 다음 미션 기대값도 50개 캠페인에 맞춰 갱신하고 관련 PC·모바일 6개 시나리오를 재검증했다.
- `npm run test:e2e:server`: 기존 다인·AI 4개와 새 준비 미션 12개, 총 16개 시나리오 통과. 초대 링크 입장, 독립 사용자 손패, WS 동기화, 준비 중 재접속과 동일 결과를 검사했다.
- 화면 보완 후 미션 5·11·23·27·40·41·46의 7개 실시간 시나리오를 재검증했다. 23/40의 실제 토큰 변경·원복·확정, 27의 실제 목표 양도, 모바일 가로 넘침 검사도 통과했다.
- `VITE_BACKEND_MODE=server npm run build`, `npm run build:server`: 통과. 프론트·서버 최종 빌드를 로컬 `http://localhost:8080`에 실행하고 `/healthz`, capabilities의 준비 상태·미션 50개·규칙 버전을 확인했다.
- `graphify update .`: 377개 노드·806개 연결로 갱신. `git diff --check` 및 로컬 문서 링크 검사 통과.
