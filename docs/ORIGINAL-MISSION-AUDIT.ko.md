# 원작 50개 미션 재대조 기록

확인일: 2026-09-14 · 적용 규칙: `crew-p9-50-3` · Planet Nine 3~5인 기본형

## 결론과 이전 구현의 문제

미션 50개를 임의로 새로 설계한 것은 아니다. 목표 수, 순서 토큰, 교신 제한과 특수 조건은 원작 항해일지를 기반으로 했다. 그러나 이전 데이터의 `첫 번째 신호`, `심우주 탐사` 같은 제목은 자체 창작이었고, 17번 종료 및 5·33번 선택 범위에 원문 직접 확인보다 추론·커뮤니티 주장을 우선한 판정이 섞여 있었다. 따라서 이전 상태를 원작 그대로라고 부르는 것은 정확하지 않다.

이번에는 창작 제목을 `미션 01`부터 `미션 50`까지 번호로 교체하고 설명을 확인된 기능 조건으로 다시 작성했다. 원작의 이야기나 공식 한국어 번역문을 복제한 것이 아니다. 아래 표와 현재 설명은 플레이 규칙의 자체 한국어 요약이다.

## 수정한 판정과 표현

- **17번:** 목표 2개 완료 시, 그 트릭까지 일반 9가 승리하지 않았다면 즉시 성공한다. 공식 규칙서 인쇄 10쪽의 일반 종료 규칙을 적용한 결론이다. 항해일지에 없는 `일반 9 네 장 모두 소진` 또는 `마지막 트릭 대기` 조건을 추가하지 않는다. 목표를 완료하는 바로 그 트릭에서 일반 9가 승리하면 실패가 우선한다. 목표가 없는 16번은 전체 실제 트릭 동안 제한을 지켜야 한다.
- **5·33·41번:** 확보한 영문 사본은 전원에게 질문하고 지휘관이 대원을 정하도록 서술한다. 이 세 미션에 별도의 지휘관 결정 기호나 자신 제외 문구는 없다. 지휘관도 응답하고 자신을 선택할 수 있게 한다. 5번은 `좋음/나쁨`, 33·41번은 `예/아니오`로 표시한다. 다른 인쇄 판본에 제한 문구가 있다는 커뮤니티 보고는 실물 대조 전까지 미확정으로 남긴다.
- **11번과 지휘관 결정 20·27·37번:** 다른 대원을 고르라는 별도 근거가 있으므로 자신 제외를 유지한다. 5·33·41번의 맞춤 조건에 지휘관 결정의 제한을 자동 적용하지 않는다.
- **D 교신:** 최고·최저·유일 위치를 공개하지 않는다. 공식 규칙서처럼 카드 옆에 빨간 토큰을 표시하며 내부 값도 `hidden`으로 유지한다.
- **50번:** 역할은 팀이 합의한다. UI의 지휘관 확정은 합의 결과를 저장하는 조작이며 지휘관의 독단적인 역할 분배 규칙으로 설명하지 않는다.
- **색상 대응:** 원작 분홍색을 사용자가 요청한 검은색 타마마로 바꾼 외형 수정은 유지한다. 따라서 46번의 분홍 9와 분홍 카드 전체가 앱에서는 검은 9와 검은 카드 전체다.

## 유지하는 예외·미확정 사항

12번 교신 카드 보호 및 교환 뒤 토큰 위치 유지는 저자와 논의했다는 BGG 답변의 중계에 근거한다. 항해일지에 직접 적힌 문구나 출판사 정오표로 포장하지 않는다. 판본 차이와 출처 수준은 [판정 기록](./MISSION-RULINGS.ko.md)에 남긴다.

이미 진행 중인 `crew-p9-50-2` 판은 저장된 판정을 유지한다. 다음 미션이나 재도전에서 `crew-p9-50-3`을 사용한다. 새 미션 설명은 즉시 갱신되므로 구버전 17번 진행 화면에는 기존 추가 진행량을 별도로 유지한다. Supabase 원격 게임 저장소와 배포 완료를 의미하지 않는다.

## 구현 참조 및 검증

- 규칙 데이터: `shared/missions.json`, `shared/missionRules.ts`
- 공유 엔진: `src/game/engine.ts`; Node 서버와 로컬 데모에서 함께 사용
- 준비 화면·데모: `PreparationPanel.tsx`, `src/game/demoPolicy.ts`
- 검증 결과: [미션 구현·검증 기록](./MISSION-IMPLEMENTATION-RESULTS.ko.md)

테스트 통과는 구현 내부의 일관성을 확인하는 증거다. 원작 일치의 근거는 위 자료와 직접 대조한 문구·기호이며, 테스트로 출처 확인을 대신하지 않는다.

## 2026-09-14 목표 수 공개와 지휘관 응답 재확인

Aside 조사로 [출판사 영문 규칙서](https://www.thamesandkosmos.com/manuals/full/691868_Crew_Manual.pdf)의 인쇄 8·17–18쪽을 재확인했다. 목표 카드의 **총수는 공개 정보**이며, 카드 색·숫자의 공개 시점과 구분한다.

| 절차 | 총수 | 카드 내용의 공개 시점 |
|---|---|---|
| 일반 목표 선택 | 공개 | 선택 전에 지정 수량 전체를 앞면으로 공개 |
| 지휘관 결정(20·27·37) | 2·3·4장 공개 | 담당자를 정한 뒤 공개 |
| 분배(24·32·36·43) | 6·7·7·9장 공개 | 한 장씩 공개하고 응답·배정을 반복 |
| 33번 특수 조건 | 0장 | 목표 카드 대신 지정 대원의 일반 카드로 정확히 한 트릭 획득 조건 |

33번의 조건은 기존 [항해일지 사본](https://cdn.1j1ju.com/medias/dd/5a/3a-the-crew-the-quest-for-planet-nine-log-book.pdf) 인쇄 14–15쪽과 함께 대조했다. 사본을 공식 한국어 번역본으로 취급하지 않는다.

지휘관 역시 대원이라는 일반 설명과 각 대원이 응답한다는 절차를 결합해 지휘관 자신의 응답을 포함한다. 별도의 ‘스스로에게 질문한다’는 문장을 직접 인용한 것으로 해석하지 않는다. 지휘관 결정의 자기 지정 금지와 분배의 자기 지정 가능은 서로 다른 규칙이다. 이번 변경은 기존 v3 판정을 유지하고, 본인 응답 후 전원 응답이 끝났을 때 지휘관이 직접 선택해야 한다는 UI 안내를 수정했다.
